# 관리자 게시글 → 고객 게시판

고객 게시판은 관리자와 동일한 서버 저장소의 `records.articles`를 `/api/boards`로 조회합니다. 첨부 HTML에 고정되어 있던 예시 글은 고객 게시판에 표시하지 않습니다. 헤더·푸터·게시판 CSS는 그대로 유지하며 데이터와 클릭 연결만 변경했습니다.

| 관리자에서 관리하는 게시판 | 고객 화면 |
| --- | --- |
| 골드마스터 게시판 / 꽃게선생 게시판 | 무료주식정보 `/freeInfo`의 전문가별 글. ‘상단 공지’를 켠 글은 상단 공지 목록 |
| 공지사항 | 고객센터 → 공지사항 `/support/notice` |
| 자주묻는질문 | 고객센터 → FAQ `/support/faq`. 회원정보·결제·이용문의 범주와 답변 내용 연결 |
| 이벤트 | 고객센터 → 이벤트 `/support/event`. 제목·기간·대표 이미지·본문 연결 |
| 이벤트의 카테고리 ‘당첨자발표’ | 같은 이벤트 페이지의 ‘이벤트 당첨자 보기’ 탭 |

관리자 기존 게시글 등록·수정 폼에서 게시판·제목·본문·공개 범위·게시일을 입력하고 저장합니다. 프론트 새로고침 또는 해당 탭으로 돌아올 때 저장된 내용을 다시 불러옵니다. 수정·삭제·비공개 변경도 같은 방식으로 반영되며, 글이 없으면 원본 빈 목록을 표시합니다. 별도 프론트 HTML 수정은 필요하지 않습니다.

‘공개/전체공개’는 누구나 읽을 수 있습니다. ‘회원전용/무료회원공개’는 실제 로그인 확인 후 본문이 제공됩니다. ‘유료회원공개’는 검증된 활성 유료 회원 또는 허용 관리자·해당 전문가만 본문이 제공됩니다. 권한이 없는 글은 제목 등 목록 정보만 제공하고 본문·상세 이미지는 전달하지 않습니다. ‘비공개’는 목록에서도 제외합니다. 회원 연결은 기존 인증 어댑터의 신뢰된 회원 ID/openId와 관리자 회원 레코드를 연결하며 이름으로 추측하지 않습니다.

## 프론트·관리자 별도 배포

두 Vercel 프로젝트는 **같은 MySQL `DATABASE_URL`과 같은 운영 상태 테이블 설정**을 사용해야 게시글·영상·쿠폰 변경을 공유합니다. DB 없는 Vercel 테스트는 관리자 초기 데이터 조회만 제공하며 실제 작성/수정 저장은 차단됩니다. 서로 다른 DB를 쓰면 관리자에서 저장한 글이 다른 프론트에 반영되지 않습니다. `docs/프론트_관리자_분리배포.md`와 `docs/Vercel_테스트배포_관리자설정.md`의 기존 설정을 그대로 사용합니다.

주요 소스는 `server/managed-boards.mjs`, `server/index.mjs`, `components/renewal/OriginalDesignPage.tsx`, `components/renewal/OriginalContentPages.jsx`입니다. 관리자 게시글 편집 폼은 기존 `components/admin/AdminApplication.jsx`에 있습니다.
