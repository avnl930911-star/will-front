# 관리자 데이터·자동 메뉴·결제 연결 검증

- 자동 테스트 50개 통과: 실제 관리자 저장소 게시·수정·비공개·삭제 반영, 리치 본문 안전 처리, 회원 글 보호, 신규 전문가 및 동적 영상 소유권, 상품 추가·변경·삭제·숨기기와 그룹 파생, 쿠폰 예약/만료, 영상 포인트 및 실제 주문 권한, 이지페이 응답 검증, 부분 승인·실패·승인 불명 상태의 영속 보존.
- `npm run check` 및 `npm run build` 통과. Vercel API/인증/미디어 라우트와 프론트·관리자 독립 배포 정책을 유지.
- 고객 원본 결제 팝업 검사: 교육영상 카드·영상 포인트·혼합 결제 표시, 실제 혼합 견적 요청의 포인트 금액 전달, VIP 카드 전용 표시, 시뮬레이션 승인 버튼 제거, 브라우저 실행 오류 없음.
- 원본 디자인 CSS·로고 CSS·기본 고객 스타일은 변경하지 않음. 전문가/상품/게시글 내용은 관리자 데이터로 대체하고 결제 방식·포인트 명칭·오류 안내만 요구에 맞게 연결.
- API `/api/registry`, `/api/boards`, `/api/catalog`는 JSON 응답. 비로그인 고객 지갑은 `401 AUTH_REQUIRED`로 보호.

## 아직 실제 운영 환경에서 필요한 작업

실제 KICC 가맹점ID·Secret Key, 테스트/운영 API 주소 및 도메인 등록, 같은 영속 MySQL, 기존 검증된 고객 로그인 ID와 관리자 회원 ID 연결을 설정해야 합니다. 실제 가맹점 자격이 제공되지 않아 실제 카드 청구·승인·취소를 실행하지 않았습니다. 자동 검사는 fake provider와 격리된 저장소를 사용했으며, 실제 운영 잔액과 카드에 영향을 주지 않았습니다. 일부 승인·승인 불명·수동 환불 필요 상태는 실제 상점 관리자에서 거래 대사 후 처리해야 하며, 코드에서 환불 완료를 위장하지 않습니다.
