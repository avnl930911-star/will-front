## 실제 화면 연결 검사

테스트용으로 분리한 임시 저장소·서명 키·세션에서 수행했습니다. 운영 FTP·실제 고객 DB·실제 계정은 사용하지 않았습니다. 확인한 흐름은 다음과 같습니다.

- 관리자 최종 9열 상품표, 수신자 외곽 1개/4행, 자동문자·전문가게시판의 검색 제외 유지.
- 두 전문가 주식교육영상 목록이 오류 없이 열리고 ‘쿠폰’ 버튼 표시.
- 기존 등록 팝업에서 실제 MP4 업로드 → 관리자 상태 저장 → 고객용 공통 카탈로그 반영.
- 고객용 원본 목록 디자인에서 검색 → 상세 → 실제 video 플레이어 메타데이터 로딩.
- 업로드한 파일의 HTTP Range 요청이 206과 정확한 부분 바이트를 반환.
- 관리자 비공개 변경 → 고객 목록 제외·재생 차단. 가격 변경 → 유료/금액 반영·미연결 구매 권한 차단.
- 전체 매출 XLSX 다운로드 유지.
- 실제 서버 전문가 역할로 담당 메뉴·회원 목록을 조회하고 연락처 미노출 확인.
- 전문가 담당 영상 수정 → 범위 제한 서버 저장 → 새로고침 후 변경 유지.

브라우저 JavaScript 오류: **0개**. 기계 판독 결과는 `browser-integration-results.json`입니다.

## 디자인 범위

앱을 독립 HTML이나 iframe으로 감싼 형태가 아니라 실제 Next.js React 컴포넌트로 이식했습니다. **상품 상세의 HTML/iframe 미리보기**는 기존 수정 요청에 포함된 기능이므로 제거하지 않았습니다. 고객용 화면은 첨부 프론트의 제목·구분선·배너·레일·상세 배치를 재사용했습니다. 두 패키지의 예시 영상 메타데이터는 공통 카탈로그로 조정했습니다.

## 실제 운영 전 확인

FTP 계정·실제 경로·HTTPS 영상 URL 매핑·FTPS 지원 여부, 기존 고객 로그인·구매 DB·PG·문자발송·실제 시청 로그, 운영 MySQL 연결은 실제 값이 없어서 검증하지 않았습니다. 코드와 연결점이 준비되었다는 의미이며, 해당 외부 시스템이 이미 연결되어 운영 중이라는 의미는 아닙니다.

초기 회원/강의/결제 값은 시안 예시입니다. 운영 전 데이터 이관과 예시 정리가 필요합니다. JSON 로컬 모드는 단일 프로세스 전용이며 운영에서는 영속 디스크/DB와 호스팅 접근 보호가 필요합니다.
