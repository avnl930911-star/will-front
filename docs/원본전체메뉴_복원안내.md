# 첨부 HTML 고객 화면 복원

기준 파일은 사용자가 제공한 `최종리뉴얼디자인완성본.html`입니다. 기존 통합 과정에서 일부 메뉴를 간소화 화면으로 대체한 부분을 제거하고, 첨부 파일의 실제 React 렌더링 함수·데이터·내장 이미지·스타일을 재사용했습니다.

| 경로 | 첨부 원본 화면 |
| --- | --- |
| `/` | 최종 리뉴얼 메인 |
| `/about` | 회사소개, 회사 개요·비전·철학·약속 및 섹션 탐색 |
| `/guide` | 이용방법 5단계, 계좌 복사, 서비스 안내 |
| `/freeInfo` | 무료주식정보 게시글 목록, 공지·전문가·검색·정렬·회원 안내 |
| `/freeInfo?post=글ID`, `/freeInfo/articles/글ID` | 게시글 상세 |
| `/paidInfo` | 원본 주식교육영상 목록·탭·검색·상세 |
| `/vip` | 원본 VIP 상품·기간 선택·소개·결제 팝업 |
| `/support/notice` | 원본 공지사항 목록·검색·상세 |
| `/support/faq` | 원본 FAQ 카테고리·검색·답변 |
| `/support/event`, `/support/event/이벤트ID` | 원본 이벤트 목록·상세 |

상단 헤더는 메인의 원본 헤더를 공통으로 사용합니다. 메뉴 글자의 크기·폰트·간격은 바꾸지 않았습니다. 로고만 기존 다른 고객 페이지의 이미지와 표시 치수(데스크톱 91×48, 850px 이하 너비 79, 650px 이하 72×38)에 맞췄습니다. 푸터는 앞서 복원한 동일한 원본을 유지하며 WILLCLUB 글자만 관리자 페이지 링크로 연결됩니다.

## 유지된 연동

메인 최신 영상 4개와 교육영상 목록은 동일한 `/api/catalog` 데이터를 사용합니다. 관리자의 영상 업로드와 공개 설정이 해당 API에 반영됩니다. 원본 상세 화면의 재생 버튼은 서버가 확인한 영상 주소만 재생합니다. 영상용 쿠폰은 원본 영상 결제 팝업 안에만 입력·조회·적용 영역을 추가했으며 서버에서 소유권·유효기간·대상 영상·할인액을 검증합니다.

Vercel API 라우트와 프론트·관리자 독립 배포 설정은 유지됩니다. 두 배포를 연결하고 변경된 운영 데이터를 공유하려면 기존 안내대로 사이트 주소·실제 인증·공유 MySQL을 설정해야 합니다.

## 실제 운영 서비스와 디자인의 구분

첨부 원본 자체에도 독립 회원가입 화면은 없습니다. 원본의 ‘회원가입하기’ 클릭 안내를 유지했습니다. 실제 PG 결제·고객 프로필 저장·일반 회원 쿠폰 등록 제공자는 이 패키지에 전달되지 않았으므로, 원본 팝업 디자인을 복원하되 결제 성공·시청권 발급·프로필 저장을 허위로 처리하지 않습니다. 영상 쿠폰 검증과 할인 예정 금액 확인은 실제 API와 연결됩니다. 관리자 인증·저장·기존 권한 검증은 변경하지 않았습니다.

## 확인 결과

첨부 HTML과 같은 영상 데이터·1440px 화면 조건에서 회사소개·이용방법·무료주식정보·주식교육영상·VIP·공지사항·FAQ·이벤트의 표시 문구, 제목 스타일, 상단 메뉴 글자 스타일과 단일 헤더·푸터를 대조했습니다. 공지·FAQ의 계산된 줄 높이 차이 0.0001px는 브라우저 소수점 반올림 차이로 확인했고 실제 스타일은 바꾸지 않았습니다. 원본 결제 팝업에서 영상 쿠폰 적용·해제로 예정 금액이 갱신되고, 실제 무료 샘플 영상 재생 API가 플레이어로 연결됨을 확인했습니다. TypeScript 검사·운영 빌드·기존 서버 테스트 24개도 통과했습니다.
