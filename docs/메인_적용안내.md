# 최종 메인 디자인 적용

`/`는 첨부 `최종리뉴얼디자인완성본.html`에서 실제 홈 컴포넌트·헤더·푸터를 가져온 메인입니다. 주식교육영상 목록을 메인으로 사용하는 잘못된 연결을 제거했으며, `/paidInfo`는 기존 교육영상 컴포넌트를 별도로 사용합니다.

메인의 이미지·로고·폰트·캐러셀·운영반 카드·퀵링크와 배치는 첨부 원본을 재사용했습니다. 원본 전체 HTML을 iframe으로 감싸거나 원본의 별도 hash 라우터를 함께 실행하지 않습니다. `components/renewal/renewal.css`는 원본 메인·공통 푸터·상담 영역에 한정되어 각 페이지 본문·관리자 스타일을 변경하지 않습니다.

메인 코드는 `components/renewal/`, 원본 내장 이미지는 `public/renewal-assets/`에 있습니다. 로고는 `/`으로 이동하고, 메인 푸터의 기존 `WILLCLUB` 문구 자체가 `/admin`으로 이동합니다. 별도 관리자 문구는 추가하지 않습니다. 메인 영상 카드는 교육영상과 동일한 `/api/catalog`의 `items`를 읽으며 카드 선택 시 기존 영상 상세로 이동합니다.

원본과 적용본의 헤더·로고·배너·운영반·영상·퀵링크 배치와 폰트를 비교했습니다. 실제 메인→교육영상→로고→메인 이동, 영상 상세 링크, 공개 영상 API 반영, 모바일 가로 넘침 없음, 관리자 API 인증 보호를 확인했습니다. 관리자·영상 업로드 서버 코드는 이번 수정에서 변경하지 않았습니다.

## 상담센터 공통화

`components/support/`의 공통 버튼·고객센터 메뉴·팝업을 메인, 주식교육영상, 무료정보 및 기타 고객 페이지에서 함께 사용합니다. 원본 메인의 상담 버튼 스타일을 그대로 사용하고 교육영상 메뉴에도 상담 항목을 추가했습니다. 고객 푸터의 `WILLCLUB` 문구를 누르면 `/admin`으로 이동합니다. 실제 외부 상담 서비스는 제공되지 않아 안내 팝업만 표시하며, 채팅 서비스가 연결되었다고 표시하지 않습니다.

## 원본 푸터 전 페이지 유지

모든 고객 페이지는 `SharedOriginalFooter`에서 첨부 원본의 `OriginalFooter`를 함께 사용합니다. 문구·로고·색상·글자 크기·간격·배치를 원본과 동일하게 유지하고, 기존 `WILLCLUB` 문구만 `/admin`으로 연결합니다. 별도 관리자 문구·버튼·아이콘이나 호버 디자인을 추가하지 않습니다. 데스크톱 1440px와 모바일 390px에서 메인·교육영상·무료정보·회사소개·이용방법·VIP·공지·FAQ·이벤트·로그인의 푸터가 원본과 동일한지 대조했습니다.
