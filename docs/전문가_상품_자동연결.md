# 전문가·상품 자동 연결

관리자에서 전문가를 추가하면 저장된 전문가 레코드의 안정적인 ID로 무료주식정보 게시판과 주식교육영상 메뉴가 만들어집니다. 글/영상 등록 폼의 전문가 및 게시판 선택지도 현재 전문가 목록을 사용합니다. 이름을 바꾸어도 같은 ID의 메뉴·소유권을 유지하고 연결된 게시판명과 표시 이름을 갱신합니다. 추가 전문가를 기존 전문가로 잘못 표시하지 않습니다.

상품별 그룹 이름은 **상품명 그대로**입니다. 상품 추가·이름 변경·삭제에 따라 해당 상품의 회원 그룹과 관리자 왼쪽 회원 목록 메뉴가 갱신됩니다. 상품을 삭제해도 고객 레코드와 과거 결제·회원 서비스 이력 자체를 삭제하지 않습니다. 과거 이름으로만 저장된 회원 서비스는 이전 상품명을 보관해 호환 조회하고, 신규 연결은 안정적인 상품 ID를 사용합니다.

**숨기기는 프론트 노출만 제어**합니다. 숨긴 상품은 관리자 상품·그룹·회원 메뉴에 그대로 남아 있고 고객 VIP 상품 목록에는 표시하지 않습니다. 판매중지는 상품 자체 삭제와 다르며 결제 가능 여부를 별도로 제어합니다.

고객용 주식교육영상 포인트는 충전 잔액 `paidPoints`와 쿠폰 적립 잔액 `freePoints`를 합산한 활성 잔액입니다. 기존 사이트 잔액 `balance`는 관리자에서만 기존 보유액을 조회하는 읽기 전용 항목으로 남습니다. 고객 마이페이지·영상 결제·포인트 충전에 기존 잔액을 합산하지 않습니다. VIP는 포인트 결제를 사용하지 않습니다.

프론트와 관리자 별도 배포는 같은 MySQL 저장소를 사용해야 변경을 공유합니다. DB 없는 Vercel 테스트에서는 읽기만 가능하므로 실제 게시·상품 추가·그룹 유지·결제 기록 저장에 외부 MySQL 설정이 필요합니다.
